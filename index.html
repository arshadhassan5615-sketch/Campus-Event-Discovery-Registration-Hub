About Campus Event Hub

What is this? A simple, responsive web app that lists campus events and lets students register for a seat.

Who built it? CSE326 team — 3 members working together on Problem Statement–Based Project 1.

Technologies used? Plain HTML5, CSS3, and vanilla JavaScript (no frameworks).

Features? Search, filter by category/status, real-time capacity tracking, registration management, and responsive design for mobile/tablet/desktop.

How to use? Open index.html in your browser. Add an event in the form, then register for a seat using your student ID.
